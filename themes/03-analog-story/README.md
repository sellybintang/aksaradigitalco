# 03 — Analog Story

**Konsep:** undangan sebagai ruang cuci foto analog. Lampu merah, nampan cairan, foto "muncul" saat dicuci.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★
**Paling cocok untuk:** foto prewedding outdoor, nuansa film/analog, foto hitam-putih.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Foto di nampan pengembang yang perlahan muncul, nama tamu di selotip kertas, tombol "Nyalakan Lampu" (efek kilat) |
| Pembuka | Cetakan besar dijepit di tali jemuran |
| Kutipan | Strip film |
| Mempelai | Contact sheet "Negatif 01 / 02" |
| Hitung mundur | Timer cuci foto dengan angka merah menyala |
| Acara | Amplop cetak foto dengan stempel tanggal |
| Kisah cinta | Roll film dengan lubang sprocket |
| Galeri | Foto dijemur di tali, "tercuci" saat digulir, ketuk untuk memperbesar |
| RSVP | Form dengan pilihan kehadiran berbentuk tombol |
| Ucapan | Tulisan tangan di balik foto |
| Footer | "— Fin —" + kredit fotografer (kolom `kredit_foto`) |

**Kolom tambahan:** `foto_berdua` (foto utama di bagian pembuka), `kredit_foto`.
**Warna:** gelap `#110d0c`, merah lampu `#c8321f`, kertas `#f3ede3`, amber `#d98a3a`
**Font:** Cormorant Garamond (judul), IBM Plex Mono (label), Caveat (tulisan tangan)

**Demo:** `/demo-analog-story?to=Nama+Tamu`
Foto demo saat ini ada di `demo-data/img-private/` (tidak ikut di-commit) — ganti dengan foto berizin sebelum dipublikasikan.
