# 18 — Arabesque

**Konsep:** undangan islami bernuansa Maroko — hijau zamrud & emas, pola zellige, lengkung pintu, lentera.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★
**Paling cocok untuk:** pasangan muslim yang ingin nuansa islami yang mewah namun tidak kaku.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Lentera berayun, Bismillah, lengkung pintu Maroko berbingkai emas berisi pintu kayu berpola, nama, nama tamu |
| Buka | Pintu kayu terbuka memperlihatkan foto pasangan, lalu "masuk" ke dalam lengkungan |
| Pembuka | Bismillah, salam, kalimat pembuka, foto dalam lengkungan, nama & tanggal |
| Kutipan | QS. Ar-Rum: 21 (dari data) |
| Mempelai | Foto dalam lengkungan kecil |
| Hitung mundur | Angka di dalam bintang delapan emas |
| Acara | Kartu berbentuk lengkung dengan bintang |
| Kisah cinta | Ta'aruf → Khitbah → Mitsaqan Ghaliza (contoh) dengan bintang |
| Galeri | Foto-foto berbentuk lengkung pintu, ketuk untuk memperbesar |
| Footer | Doa *Barakallahu lakuma* (Arab + arti), salam penutup |

**Kolom yang dipakai:** `foto_sampul` (di balik pintu sampul), `foto_berdua` (foto pembuka), `kredit_foto`.
**Warna:** zamrud `#0e3b37`, emas `#c9a24a`, krem `#f6efe2`, terakota `#b5643c`
**Font:** Marcellus (judul), Amiri (Arab & aksen miring), Jost (teks)

**Demo:** `/demo-arabesque?to=Nama+Tamu`
