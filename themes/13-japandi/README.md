# 13 — Japandi

**Konsep:** minimalis Jepang-Skandinavia — tenang, banyak ruang kosong, warna alam.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★
**Paling cocok untuk:** pasangan yang suka gaya bersih & kalem, foto outdoor bernuansa natural.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Lingkaran kuas ensō tergambar perlahan mengelilingi foto bundar, nama, stempel merah (hanko) berinisial, teks vertikal di sisi |
| Buka | Pintu geser shoji menutup lalu terbuka memperlihatkan isi |
| Pembuka | Foto potret berbingkai garis tipis + nama |
| Kutipan | Di atas ensō samar |
| Mempelai | Foto bundar, nama, orang tua — dipisah garis tipis |
| Hitung mundur | Angka serif dengan pemisah garis |
| Acara | Kartu dengan aksen kayu |
| Kisah cinta | Garis waktu tipis |
| Galeri | Grid asimetris dengan ruang kosong, ketuk untuk memperbesar |
| RSVP / Ucapan | Input bergaris bawah, daftar ucapan minimalis |
| Footer | Ensō + hanko |

**Kolom yang dipakai:** `foto_sampul` (foto bundar sampul), `foto_berdua` (foto pembuka), `kredit_foto`.
**Warna:** kertas `#f4f0e8`, tinta `#2a2926`, tanah liat `#a87a55`, kayu `#c9a98a`, merah hanko `#b23a2a`
**Font:** Shippori Mincho (judul), Zen Kaku Gothic New (teks)

**Demo:** `/demo-japandi?to=Nama+Tamu`
