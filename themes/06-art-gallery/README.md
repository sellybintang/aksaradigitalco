# 06 — Art Gallery

**Konsep:** undangan sebagai pameran seni tunggal di galeri/museum.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★
**Paling cocok untuk:** pasangan dengan selera klasik-elegan, foto bergaya editorial atau hitam-putih.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Lukisan berbingkai emas di bawah lampu sorot, plakat karya, tiket masuk bertuliskan nama tamu. Tombol "Masuki Galeri" memperbesar lukisan seolah berjalan mendekat |
| Pembuka | "A Love Exhibition": nama besar gaya poster pameran + karya berbingkai putih |
| Kutipan | Teks dinding hijau galeri |
| Mempelai | Potret berbingkai hitam + label karya |
| Hitung mundur | "Pembukaan Pameran" |
| Acara | Ruang I / Ruang II |
| Kisah cinta | Koleksi permanen (Karya I, II, …) |
| Galeri | Dinding salon: bingkai emas & hitam beragam ukuran, ketuk untuk memperbesar |
| RSVP | Buku tamu |
| Ucapan | Kesan pengunjung |
| Footer | Monogram + "Terima kasih telah berkunjung" |

**Kolom yang dipakai:** `foto_sampul` (lukisan di sampul), `foto_berdua` (karya di pembuka), `kredit_foto`.
**Warna:** dinding `#f6f3ec`, tinta `#1d1c1a`, emas `#b8955a`, hijau galeri `#2f4a3e`
**Font:** Bodoni Moda (judul), Manrope (teks)

**Demo:** `/demo-art-gallery?to=Nama+Tamu`
