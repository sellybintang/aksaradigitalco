# 04 — Vinyl Record

**Konsep:** undangan sebagai album piringan hitam retro tahun 70-an.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★
**Paling cocok untuk:** pasangan pencinta musik, foto bernuansa hangat/vintage.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Sleeve album berisi foto pasangan, piringan mengintip di sampingnya, stiker "Limited Edition". Tombol "Putar Undangan" menarik piringan keluar sambil berputar |
| Pembuka | Turntable kayu dengan piringan berputar (label tengah = foto pasangan), tulisan "Now Playing" dengan equalizer |
| Kutipan | Liner notes |
| Mempelai | "Featuring" dengan piringan mini |
| Hitung mundur | Pemutar musik: waktu tersisa, progress bar, tombol kontrol |
| Acara | Tracklist Side A / Side B |
| Kisah cinta | Bonus tracks bernomor |
| Galeri | Sampul-sampul album (ketuk untuk memperbesar) |
| RSVP | Guest list |
| Amplop digital | "Support the Couple" |
| Ucapan | Fan mail |
| Footer | "Side B · The End" + ℗ tahun |

**Kolom yang dipakai:** `foto_sampul` (sleeve album), `foto_berdua` (label piringan di turntable), `kredit_foto`.
**Warna:** krem `#f2e8d5`, coklat tua `#2b1d16`, oranye `#d9622b`, mustard `#e0a83a`
**Font:** DM Serif Display (judul), Archivo (teks)
