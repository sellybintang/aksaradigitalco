# 24 — Danau Kembang Api

**Konsep:** taman danau romantis bergaya lukisan pastel — danau tosca dengan dua angsa, jembatan, landmark kota
(Monas, menara, piramida kaca, istana), lampu taman klasik, kembang api, kolibri, rumbai & kanopi bunga, mawar & peony.
**Kelas harga:** Premium · **SKU:** AD012 · **Dasar mesin:** 23-lembah-wisteria

| Bagian | Bentuk di tema |
|---|---|
| Opening | Tirai belah dua lukisan danau |
| Sampul | Kamera menyapu danau lalu mundur → lampu & kembang api (berkelip) → rumbai & kanopi (berayun) → teks nama → kolibri (melayang) → mawar & peony depan; kelopak & salju halus berjatuhan |
| Isi | 5 bagian bergantian gelap/terang: latar terang = rumbai + angsa & bunga; latar gelap = kanopi + rumpun mawar |
| Tipografi | Pinyon Script (nama), Cormorant Garamond (judul & "The Wedding of"), Cinzel (label), Plus Jakarta Sans |
