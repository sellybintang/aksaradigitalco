# 01 — Boarding Pass

**Konsep:** undangan sebagai tiket pesawat "Love Airways".
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Boarding pass dengan nama tamu sebagai *Passenger*, dibuka dengan efek sobek tiket |
| Pembuka | "Now Boarding" + foto sampul |
| Mempelai | Kartu paspor dengan stempel |
| Hitung mundur | Papan keberangkatan bandara (angka berbalik) |
| Acara | Tiket per gate + tombol peta & kalender |
| Kisah cinta | Flight log (garis rute) |
| Galeri | Kartu pos miring |
| RSVP | Online check-in |
| Amplop digital | Baggage counter + tombol salin |
| Ucapan | Arrival log |

**Warna:** navy `#0f2a44`, kertas `#fbf7ef`, amber `#e8a33d`, merah stempel `#c8553d`
**Font:** Playfair Display (nama), DM Mono (teks tiket), Inter (isi)
