# 20 — Atlas

**Konsep:** peta topografi modern — perjalanan dua penjelajah menuju satu tujuan.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★
**Paling cocok untuk:** pasangan pencinta jalan-jalan / mendaki, foto outdoor & petualangan.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Peta topografi (garis kontur **unik per pasangan**), kompas, dua penanda bernama mempelai yang rutenya bertemu di penanda tujuan bertanggal, kartu "Ekspedisi Cinta · <kota>" + "Peserta: <tamu>" |
| Buka | Rute berjalan, lalu peta memperbesar ke titik tujuan |
| Pembuka | Foto berbingkai putih dengan label kota & tanggal |
| Kutipan | Catatan perjalanan |
| Mempelai | Penjelajah A & B |
| Hitung mundur | "Jarak ke Tujuan" + penanda yang bergeser di rute mendekati hari H |
| Acara | Checkpoint 01 / 02 + tombol "Buka Rute" (Google Maps) |
| Kisah cinta | Waypoint di jalur titik-titik |
| Galeri | Foto lapangan, ketuk untuk memperbesar |
| RSVP / Hadiah / Ucapan | Daftar Peserta · Bekal Perjalanan · Buku Catatan |

**Kolom yang dipakai:** `foto_berdua` (foto pembuka), `kredit_foto`. Nama kota diambil otomatis dari bagian terakhir alamat acara pertama.
**Warna:** kertas peta `#f1ece0`, hutan `#2f4a3a`, penanda `#c4552f`, kontur `#b9ad94`
**Font:** Young Serif (judul), Inter Tight (teks), Space Mono (label)

**Demo:** `/demo-atlas?to=Nama+Tamu`
