# 19 — Nusantara

**Konsep:** adat Jawa yang elegan — marun, emas, krem, batik kawung, tenun, gunungan wayang.
**Kelas harga:** Premium (±Rp59.500) · **Tingkat:** ★★
**Paling cocok untuk:** pernikahan adat Jawa / foto berbusana adat (beskap, kebaya, paes), juga cocok untuk busana muslim formal.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | "Sugeng Rawuh", gunungan (kayon) emas bermotif kawung yang bergoyang pelan, "Pawiwahan", nama & tamu |
| Buka | Gunungan berputar & terangkat seperti pembuka wayang, lalu kelir (tirai batik) terbuka ke dua sisi |
| Pembuka | Foto dalam bingkai emas dengan ukiran sudut di atas latar kawung |
| Kutipan | Dengan gunungan kecil |
| Mempelai | "Ingkang Badhe Mangun Bale Wisma" — bingkai ukiran |
| Hitung mundur | "Ngetang Dinten" — kotak bergaris emas ganda |
| Acara | Kartu krem berbingkai ukiran (contoh: Akad, Panggih & Resepsi) |
| Kisah cinta | "Lampahing Tresna" — garis emas dengan penanda belah ketupat |
| Galeri | Foto berbingkai ukiran, ketuk untuk memperbesar |
| Footer | Gunungan + "Matur Nuwun" |

Subjudul berbahasa Jawa bersifat hiasan; judul utama tetap berbahasa Indonesia agar mudah dipahami semua tamu.

**Kolom yang dipakai:** `foto_berdua` (foto pembuka), `kredit_foto`. Sampul tidak memakai foto (gunungan).
**Warna:** marun `#5b1a1d`, emas `#c9a14a`, krem `#f6eddb`
**Font:** Cinzel (judul), Cormorant Garamond (teks), Jost (label)
