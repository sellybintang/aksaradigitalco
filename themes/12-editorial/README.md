# 12 — Editorial

**Konsep:** undangan sebagai majalah fashion edisi spesial.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★
**Paling cocok untuk:** foto prewedding studio / bergaya fashion, terutama close-up yang kuat.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Foto layar penuh + nama majalah besar "AMOUR", cover lines ("Eksklusif: Kisah …", "Untuk pembaca istimewa: <tamu>"), barcode |
| Buka | Sampul dibalik seperti halaman majalah |
| Pembuka | Daftar Isi bernomor halaman — bisa diklik untuk melompat ke bagian |
| Kutipan | "Dari Meja Redaksi" dengan huruf awal besar (drop cap) |
| Mempelai | Profil + pull quote merah |
| Hitung mundur | "Terbit Sebentar Lagi" — angka Bodoni besar |
| Acara | Agenda dengan tanggal besar |
| Kisah cinta | Feature story bergaya artikel |
| Galeri | Photo essay asimetris, ketuk untuk memperbesar |
| Ucapan | Surat Pembaca |
| Footer | Kolofon: Pemimpin Redaksi (mempelai), Penerbit (keluarga), Fotografer, Tata Letak |

**Kolom yang dipakai:** `foto_sampul` (sampul majalah — paling bagus foto close-up potret), `foto_berdua` (daftar isi), `kredit_foto`.
**Warna:** putih, hitam `#0d0d0d`, merah `#d7263d`
**Font:** Bodoni Moda (judul), Inter (teks)

**Demo:** `/demo-editorial?to=Nama+Tamu`
