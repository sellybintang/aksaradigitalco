# 15 — Café Menu

**Konsep:** undangan sebagai kafe/kedai kopi modern.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★
**Paling cocok untuk:** pasangan muda & santai, pencinta kopi, foto casual bernuansa coklat-krem.

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Jendela kafe melengkung berisi foto + tulisan neon nama, lalu struk pesanan tercetak dari printer: "Atas nama <tamu>", "1x Doa Restu — Priceless", "TOTAL: Kehadiran Anda" |
| Pembuka | "Today's Special" + foto dengan stiker "Fresh Brew" |
| Kutipan | Barista's note di kertas kraft berselotip |
| Mempelai | Signature blend — kartu menu dengan foto bundar |
| Hitung mundur | Cangkir kopi beruap yang makin penuh mendekati hari H + angka hitung mundur |
| Acara | Papan menu gelap dengan garis titik-titik ("Akad Nikah ........ 08:00") |
| Kisah cinta | "Our Blend" bernomor |
| Galeri | Foto polaroid miring di atas kraft, ketuk untuk memperbesar |
| RSVP | Reservasi tempat |
| Amplop digital | Tip jar |
| Ucapan | Sticky notes warna-warni |
| Footer | Struk penutup "Terima kasih telah mampir" |

**Kolom yang dipakai:** `foto_sampul` (jendela kafe), `foto_berdua` (Today's Special), `kredit_foto`.
**Warna:** krem `#f7f1e8`, espresso `#3b2a20`, latte `#c8a27c`, karamel `#b8763e`, sage `#7d8b6a`
**Font:** Fraunces (judul), DM Mono (struk & label), Outfit (teks)
