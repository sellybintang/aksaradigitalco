# 08 — Cinema Premiere

**Konsep:** undangan sebagai pemutaran perdana film bioskop.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★
**Paling cocok untuk:** foto prewedding sinematik (gelap, dramatis, gerak/blur, hitam-putih).

| Bagian | Bentuk di tema |
|---|---|
| Sampul | Foto layar penuh dengan letterbox hitam, "… mempersembahkan", judul besar gaya poster, "Coming Soon", "Special Screening untuk <tamu>", label rating SU |
| Buka | Letterbox menutup lalu hitung mundur film klasik 3-2-1 |
| Pembuka | Poster film layar penuh + billing block (teks kecil kredit di bawah poster) |
| Kutipan | Gaya teks subtitle |
| Mempelai | "Starring" — kartu pemeran "sebagai Mempelai Pria/Wanita" |
| Hitung mundur | "Premiere dalam" |
| Acara | Tiket bioskop Studio 1 / Studio 2 dengan sobekan kursi VIP |
| Kisah cinta | Behind the scenes, nomor adegan di papan clapper |
| Galeri | Movie stills (layar lebar 2.35:1 + potret), ketuk untuk memperbesar |
| RSVP | Reservasi kursi |
| Ucapan | Ulasan penonton dengan bintang |
| Footer | Credit title: pemeran utama, produser (orang tua), sinematografi (fotografer) |

**Kolom yang dipakai:** `foto_sampul` (layar sampul), `foto_berdua` (poster), `kredit_foto` (muncul sebagai "Sinematografi").
**Warna:** hitam `#0a0a0b`, krem `#f4efe6`, merah `#c1272d`, amber `#f5b942`
**Font:** Bebas Neue (judul poster), Instrument Serif (aksen miring), Inter (teks)

**Demo:** `/demo-cinema-premiere?to=Nama+Tamu`
