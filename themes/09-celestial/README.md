# 09 — Celestial

**Konsep:** langit malam yang tenang & romantis, dengan peta bintang dan fase bulan pernikahan.
**Kelas harga:** Premium (±Rp50 ribu) · **Tingkat:** ★★★
**Paling cocok untuk:** semua jenis foto; paling indah dengan foto senja/malam atau outdoor.

| Bagian | Bentuk di tema |
|---|---|
| Latar | Langit berbintang yang berkelip pelan (kanvas, ringan) |
| Sampul | Peta bintang berbentuk medali dengan rasi berbentuk hati yang **unik per pasangan** (dibuat dari slug + tanggal), teks melingkar nama · tanggal · kota |
| Buka | Bintang-bintang melesat (efek warp) lalu masuk ke isi |
| Pembuka | Foto berbentuk lengkung dengan bingkai emas tipis |
| Hitung mundur | Kartu kaca + **fase bulan asli** pada malam pernikahan (Purnama, Sabit Awal, dll — dihitung otomatis) |
| Acara | Kartu kaca |
| Kisah cinta | Garis waktu berupa rasi bintang |
| Galeri | Foto membulat, ketuk untuk memperbesar |
| Ucapan | "Doa yang dititipkan" dengan ikon bintang |
| Footer | Peta bintang kecil |

**Kolom yang dipakai:** `foto_berdua` (foto pembuka), `kredit_foto`. Sampul tidak memakai foto (peta bintang).
**Warna:** malam `#0b1026`, indigo `#1d2756`, cahaya bintang `#f4efe1`, emas `#d8b46a`
**Font:** Cormorant Garamond (judul), Raleway (teks)

**Demo:** `/demo-celestial?to=Nama+Tamu`
